# UnsecuredAPIKeys — Открытая версия

Комплексная платформа для обнаружения, валидации и отслеживания незащищенных API-ключей в различных репозиториях кода и на платформах. Этот проект предназначен для образовательных целей и повышения осведомленности о безопасности, демонстрируя, насколько легко API-ключи могут быть раскрыты в публичных репозиториях.

## 🏗️ Архитектура

Проект состоит из нескольких взаимосвязанных компонентов:

- **WebAPI** (.NET 9): Основной бэкенд, предоставляющий REST эндпоинты и SignalR.
- **UI** (Next.js): Фронтенд-интерфейс с образовательным контентом и функциями поиска ключей.
- **Python Version** (SQLAlchemy + aiogram + httpx): Полный порт ядра на Python с мощным Telegram-ботом.

## 🐍 Версия на Python (Новое!)

Весь основной функционал был полностью переписан на Python для обеспечения максимальной производительности и удобства администрирования.
Код Python-версии доступен в директории `python_version/`.

**Разработка порта велась здесь:** [GitHub Branch](https://github.com/Hshdhr1/UnsecuredAPIKeys.Lite/tree/python-port-core-14703047987991639479)

### Особенности Python-версии:
- **Асинхронная архитектура**: Использование `asyncio` и `httpx` для параллельной проверки сотен ключей.
- **Multi-Source Scraper**: Поддержка автоматического поиска в **GitHub**, **GitLab** и **SourceGraph**.
- **Selenium Parsing**: Мощный парсинг GitHub через браузер (Selenium) в обход лимитов API.
- **Telegram Admin Bot**: Управление системой через Telegram на базе `aiogram` v3.
  - Цветные кнопки (Bot API 9.4+) для удобного управления.
  - Уведомления о найденных ключах в реальном времени.
  - Интерактивная кнопка «🔎 Проверить» для мгновенной валидации прямо из чата.
- **Поддержка современных моделей (2026)**: GPT-5.4, Claude 4.6, Gemini 2.5 и др.
- **13+ Провайдеров**: OpenAI, Anthropic, Google (Gemini), Groq, OpenRouter, Mistral, Moonshot (Kimi), xAI (Grok), Zhipu AI (GLM), Perplexity, DeepSeek, Stripe, HuggingFace.
- **Умная детекция фейков**: Встроенные эвристики для автоматической фильтрации мусорных и поддельных ключей (например, повторы символов или "ebani/idinahui").

## 🛠️ Полный гайд по установке (Python)

### 1. Предварительные требования
- **Python 3.12** или выше.
- **Google Chrome** (для работы Selenium-парсера в headless режиме).
- **Telegram Bot Token** (получить у [@BotFather](https://t.me/BotFather)).

### 2. Клонирование и подготовка
```bash
git clone https://github.com/Hshdhr1/UnsecuredAPIKeys.Lite.git
cd UnsecuredAPIKeys.Lite
```

### 3. Настройка виртуального окружения
Рекомендуется использовать venv:
```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```

### 4. Установка зависимостей
```bash
pip install -r python_version/requirements.txt
```

### 5. Настройка переменных окружения
Создайте файл `.env` в корневой директории проекта:
```env
# URL базы данных (SQLite создастся сама, для PostgreSQL: postgresql+asyncpg://user:pass@host/db)
DATABASE_URL=sqlite+aiosqlite:///dev.db

# Токен вашего Telegram бота
TELEGRAM_BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrSTU

# Ваш Telegram ID (чтобы бот слушался только вас)
# Узнать ID можно у бота @userinfobot или @myidbot
TELEGRAM_ADMIN_ID=123456789
```

### 6. Запуск проекта
Запустите основной скрипт из корневой директории. Все таблицы в базе данных будут созданы автоматически:
```bash
# Запуск через PYTHONPATH, чтобы правильно работали импорты
PYTHONPATH=. python3 -m python_version.src.main
```

### 7. Работа с Telegram ботом
После запуска напишите боту `/start`. Основные функции меню:
- **📦 Выгрузить ключи**: Вывод последних найденных ключей из базы данных.
- **🔑 Добавить токен**: Добавление GitHub (`ghp_...`), GitLab (`glpat-`) или SourceGraph (`sgp_`) токенов для сканирования через API.
- **🌐 Источники**: Просмотр списка добавленных токенов и их статуса.
- **🌐 Selenium Парсинг**: Запуск поиска через браузер по ключевым словам для обхода ограничений API GitHub.
